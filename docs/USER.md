# Manuel participant

Aucun compte n’est requis pour un invité.

1. Scanner le QR affiché en salle.
2. Vérifier l’objet, la date et le lieu.
3. Renseigner civilité, nom, prénom, fonction, structure, email, téléphone.
4. Signer au doigt.
5. Valider. Le bouton se désactive.

En cas de doublon : « Vous êtes déjà enregistré(e) pour cette réunion à HH:MM. »

Si le QR est expiré (mode dynamique), demander l’affichage du code actuel.
